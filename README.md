# Eavesdrop — website

Landing page and privacy policy for [Eavesdrop](https://eavesdrop.lemonsqueezy.com), a Chrome extension that shows YouTube comments in a floating panel over the video.

Static HTML/CSS, served with GitHub Pages. No build step, no trackers.

- `index.html` — landing page
- `privacy.html` — privacy policy (link this URL in the Chrome Web Store listing)
- `style.css`, `assets/` — styles, icon, share-card image

When the Chrome Web Store listing is live, set `CHROME_WEB_STORE_URL` at the bottom of `index.html`.
